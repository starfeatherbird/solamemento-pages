만일의 노트 개인정보처리방침

시행일: 2026년 7월 21일

「만일의 노트」(이하 "본 앱")는 유사시를 대비해 가족을 위한 정보를 기기에 기록하는 앱입니다. 개발자는 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리방침을 안내합니다.

1. 개인정보를 수집하지 않습니다

  • 개발자는 어떠한 서버도 운영하지 않으며, 이용자의 개인정보를 수집·저장·전송하지 않습니다.
  • 본 앱에는 회원가입, 로그인, 광고, 분석(애널리틱스) 기능이 없습니다.

2. 모든 기록은 기기 안에만 저장됩니다

  • 이용자가 입력한 모든 기록은 이용자 기기의 내부 저장소에만 보관됩니다.
  • 백업·공유 파일은 이용자가 직접 생성하며, 전달 여부와 대상은 전적으로 이용자가 결정합니다.
  • 앱을 삭제하면 기기에 저장된 모든 기록이 함께 삭제됩니다(이용자가 별도로 내보낸 백업 파일 제외).

3. 선택 기능: AI 사진 인식

이용자가 본인의 API 키를 직접 등록한 경우에만 사용할 수 있는 선택 기능입니다.

  • 이용자가 선택한 사진과 관련 텍스트가 이용자의 키로 Google Gemini API 또는 Anthropic Claude API에 기기에서 직접 전송됩니다. 개발자의 서버를 경유하지 않습니다.
  • 전송된 데이터의 처리에는 각 제공사의 개인정보처리방침이 적용됩니다: Google · Anthropic
  • API 키는 이용자 기기에만 저장되며 외부로 전송되지 않습니다(해당 API 호출 시의 인증 제외).
  • 이 기능을 사용하지 않으면 어떠한 데이터도 기기 밖으로 나가지 않습니다.

4. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

5. 방침의 변경

본 방침이 변경되는 경우 이 페이지를 통해 공지합니다.
