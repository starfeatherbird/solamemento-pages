이정표 개인정보처리방침

시행일: 2026년 10월 2일

「이정표」(이하 "본 앱")는 고민을 적고 타로 카드 세 장을 뽑으면 AI가 먼저 고려할 방향과 작은 행동을 정리해 주는 상담 앱입니다. 개발자(솔라메멘토)는 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리방침을 안내합니다.

1. 기본 원칙 — 기록은 기기에, 계정은 선택

  • 본 앱은 계정 없이 사용할 수 있으며, 이 경우 상담 기록은 이용자 기기 안에만 저장됩니다.
  • 상담 결과를 만들기 위해 이용자가 적은 고민 내용은 개발자의 서버를 거쳐 AI 서비스에 전송됩니다(2항). 이것은 계정 유무와 관계없이 상담을 요청할 때마다 일어나는 핵심 기능입니다.
  • 안드로이드 앱에는 화면 하단에 배너 광고가 표시되며(5항), 광고 제거를 구매하면 사라집니다. 웹판에는 광고가 없습니다.
  • 본 앱에는 분석(애널리틱스) 도구와 서버 푸시 알림이 없습니다.
  • 상담 결과는 참고용 제안이며 의료·법률·재정 전문 상담을 대신하지 않습니다. 본 앱은 미래나 타인의 마음을 확정적으로 알려 주지 않습니다.

2. 핵심 기능: AI 상담 결과 생성

이용자가 "함께 정리하기"를 눌러 상담을 요청하면 다음 정보가 개발자의 서버(Supabase Edge Function)로 전송되고, 서버는 이를 AI 서비스에 전달해 결과 문장을 받습니다.

항목내용목적
고민 내용, 상황 확인 답변, 보충 내용, 추가 질문이용자가 직접 입력한 텍스트상담 결과 생성
뽑힌 카드와 방향카드 이름과 정·역방향상담 결과 생성
  • AI 서비스: Anthropic(Claude)을 기본으로 쓰고, 장애 시 Google(Gemini)로 전환합니다. 전송된 텍스트의 처리에는 각 제공사의 방침이 적용됩니다: Anthropic · Google. 두 제공사 모두 API 로 전달된 데이터를 모델 학습에 쓰지 않는다고 밝히고 있습니다.
  • 개발자의 서버는 고민 내용과 결과 본문을 저장하지 않습니다. 서버에는 요청 종류, 사용한 AI 모델, 소요 시간, 성공 여부, IP 주소의 짧은 해시(원문 아님), 로그인한 경우 계정 식별자만 운영·비용 관리 목적으로 기록되며 90일 뒤 삭제됩니다.
  • 호출 횟수 제한을 위해 IP 주소의 해시가 최대 3일간 보관됩니다.
  • 전송은 모두 HTTPS 로 보호됩니다.

3. 선택 기능: 로그인과 기록 동기화

휴대폰과 웹(starfeatherbird.github.io/signpost-tarot)에서 같은 기록을 보기 위해 로그인할 수 있습니다. 로그인은 Google 계정 또는 이메일로 받은 링크로 하며 비밀번호를 만들지 않습니다.

항목내용목적
이메일 주소Google 계정의 이메일 또는 입력한 이메일로그인, 본인 계정 식별, 로그인 링크 발송
동기화 기록저장한 상담 기록 전체 — 고민, 답변, 카드, 결과, 메모, 체크 상태기기 간 동기화와 복원
  • 동기화 기록은 이용자 본인만 읽고 쓸 수 있도록 데이터베이스 수준에서 제한됩니다(행 수준 보안).
  • 전송과 저장은 HTTPS 로 보호됩니다. 다만 종단간 암호화는 아니며, 기록은 서버에 평문으로 저장됩니다.
  • 보관 위치: Supabase(클라우드 데이터베이스·인증 서비스). 보관 기간: 이용자가 계정을 삭제할 때까지.
  • 로그인한 상태에서는 상담 호출 횟수를 기기(IP) 대신 계정 기준으로 셉니다.

4. 계정과 데이터 삭제

  • 앱 안에서 내 공간 → 계정 → 계정 삭제를 누르면 계정과 클라우드 기록, 구매 사용 내역이 즉시 삭제되며 되돌릴 수 없습니다. 이 기기에 있는 기록은 남습니다.
  • 계정은 두고 기록만 지우려면 내 공간 → 전체 기록 삭제를 사용합니다(이 기기와 클라우드 기록을 함께 지웁니다).
  • 앱을 삭제하면 기기에 저장된 기록이 함께 삭제됩니다(로그인한 경우 클라우드 기록은 위 방법으로 별도 삭제).
  • 앱을 열 수 없는 경우 계정 삭제 안내 페이지의 방법으로 이메일로 요청할 수 있습니다.

5. 광고와 인앱 구매 (안드로이드 앱)

안드로이드 앱은 Google AdMob 을 통해 화면 하단에 배너 광고를 표시합니다. 광고를 표시하기 위해 Google 이 다음 정보를 수집·처리합니다. 개발자는 이 정보를 직접 받거나 보관하지 않습니다.

항목목적
광고 ID(Android 광고 ID), 앱 세트 ID광고 표시, 맞춤형 광고, 광고 성과 측정, 부정 클릭 방지
기기 정보(기종, 운영체제 버전, 언어 등), IP 주소, 대략적 위치(IP 기반)기기에 맞는 광고 표시, 부정 행위 방지
광고 노출·클릭 등 광고와의 상호작용광고 성과 측정과 수익 정산
진단 정보(앱 실행 시간, 멈춤 비율 등)광고 SDK 성능 분석, 부정 행위 방지
  • 고민 내용, 상담 기록, 계정 이메일 등 앱 안의 기록은 광고에 전달하지 않습니다.
  • 맞춤형 광고를 원하지 않으면 기기의 설정 → Google → 광고에서 광고 ID 를 삭제하거나 재설정할 수 있습니다. 이 경우 맞춤형이 아닌 일반 광고가 표시됩니다.
  • Google 의 정보 처리: Google 파트너 사이트·앱의 데이터 사용 · Google 개인정보처리방침

인앱 구매(심층 상담 1회, 광고 제거)는 Google Play 결제로 처리됩니다.

  • 카드 번호 등 결제 정보는 Google 이 처리하며 개발자에게 전달되지 않습니다.
  • 구매 확인·복원을 위해 RevenueCat(구매 검증 서비스)이 Google Play 의 구매 내역과 이용자의 계정 식별자(로그인한 경우 Supabase 사용자 ID, 아니면 익명 ID)를 처리합니다. 개발자의 서버는 심층 상담 구매를 어느 상담에 사용했는지만 기록합니다. RevenueCat 의 방침: RevenueCat Privacy Policy
  • 심층 상담 구매는 로그인한 계정에 묶입니다. 광고 제거는 Google 계정에 연결되어 같은 Google 계정을 쓰는 기기에서 다시 설치해도 "구매 복원"으로 유지됩니다. 환불된 구매는 해당 기능이 해제됩니다.

6. 내보내기·가져오기와 공유

기록을 파일로 저장하거나 불러오는 기능, 결과를 다른 앱으로 공유하는 기능은 이용자가 직접 실행하며, 파일과 공유 내용의 보관·전달은 이용자가 결정합니다.

7. 제3자 제공 및 위탁

  • 개발자는 이용자 정보를 판매하지 않으며, 앱 안의 기록을 광고 목적으로 제3자에게 제공하지 않습니다.
  • 상담 결과 생성을 위해 Anthropic PBC 와 Google LLC 의 AI API 가 이용자가 입력한 텍스트를 처리합니다(2항, 위탁).
  • 안드로이드 앱의 광고는 Google LLC(AdMob)가, 인앱 결제는 Google LLC(Google Play)가, 구매 검증은 RevenueCat, Inc. 가 처리합니다(5항).
  • 로그인·동기화에는 Supabase Inc. 가 데이터베이스와 인증 서비스를 제공합니다(위탁). Google 로그인을 쓰는 경우 Google 이 인증을 처리합니다.
