분기점 개인정보처리방침

시행일: 2026년 9월 8일

「분기점」(이하 "본 앱")은 아침 글쓰기로 머리를 비우고 오늘 꼭 할 일 3개를 고르는 플래너입니다. 개발자(솔라메멘토)는 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리방침을 안내합니다.

1. 기본 원칙 — 기록은 기기에, 계정은 선택

  • 본 앱은 계정 없이 사용할 수 있으며, 이 경우 모든 기록은 이용자 기기 안에만 저장되고 외부로 전송되지 않습니다.
  • 본 앱에는 광고, 분석(애널리틱스) 도구, 서버 푸시 알림이 없습니다.
  • 아래 2·4항의 정보는 이용자가 해당 기능을 직접 선택했을 때만 처리됩니다.

2. 선택 기능: 계정 만들기와 클라우드 백업

기기를 바꾸거나 폰과 웹에서 같은 기록을 보기 위해 계정을 만들 수 있습니다. 이때 처리되는 정보는 다음과 같습니다.

항목내용목적
이메일 주소, 비밀번호비밀번호는 해시 처리되어 원문이 저장되지 않습니다.로그인, 본인 계정 식별
백업 기록할 일·목표·습관과 체크 기록·모닝페이지·하루 매듭 소감·돌아온 기록·느린 편지·알림 설정(아침·저녁 시각)기기 간 동기화와 복원
  • 백업 기록은 이용자 본인만 읽고 쓸 수 있도록 데이터베이스 수준에서 제한됩니다(행 수준 보안).
  • 전송과 저장은 모두 HTTPS로 보호됩니다. 다만 종단간 암호화는 아니며, 기록 본문은 서버에 평문으로 저장됩니다. 모닝페이지나 소감처럼 민감한 내용을 클라우드에 두고 싶지 않다면 계정 없이 사용하시길 권합니다.
  • AI 기능에 쓰는 API 키(4항)는 클라우드에 올리지 않습니다.
  • 보관 위치: Supabase(클라우드 데이터베이스 서비스). 보관 기간: 이용자가 계정을 삭제할 때까지.

3. 계정과 데이터 삭제

  • 앱 안에서 설정 → 계정 · 백업 → 계정 삭제를 누르면 계정과 클라우드 백업이 즉시 삭제되며 되돌릴 수 없습니다. 이 기기에 있는 기록은 남습니다.
  • 클라우드 백업만 지우고 계정은 유지하려면 같은 화면의 클라우드 기록 삭제를 사용합니다.
  • 앱을 삭제하면 기기에 저장된 기록이 함께 삭제됩니다(계정을 만든 경우 클라우드 백업은 위 방법으로 별도 삭제).
  • 앱을 열 수 없는 경우 계정 삭제 안내 페이지의 방법으로 이메일로 요청할 수 있습니다.

4. 선택 기능: AI 도우미

이용자가 본인의 Google Gemini API 키를 직접 등록한 경우에만 동작하는 선택 기능입니다.

  • API 키는 이용자 기기의 보안 저장소에만 저장되며 클라우드 백업에 포함되지 않습니다.
  • 기능을 사용할 때 모닝페이지 본문이나 할 일 목록 같은 텍스트가 이용자의 키로 Google Gemini API에 기기에서 직접 전송됩니다. 개발자의 서버를 경유하지 않습니다.
  • 전송된 데이터의 처리에는 Google 개인정보처리방침이 적용됩니다.
  • 이 기능을 사용하지 않으면 AI 관련 데이터 전송은 일어나지 않습니다.

5. 알림

아침·하루 매듭·습관 알림은 기기 안에서 예약되는 로컬 알림입니다. 알림 서버나 푸시 토큰을 사용하지 않으며, 이용자가 알림 권한을 허용한 경우에만 표시됩니다.

6. 제3자 제공 및 위탁

  • 개발자는 이용자 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.
  • 계정 기능을 쓰는 경우 Supabase Inc.가 데이터베이스와 인증 서비스를 제공합니다(위탁).
  • AI 기능을 쓰는 경우 이용자가 직접 Google에 데이터를 전송합니다(4항).

7. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
