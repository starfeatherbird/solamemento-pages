차근차근 개인정보처리방침

시행일: 2026년 9월 9일

「차근차근 · ADHD 청소 플래너」(이하 "본 앱")는 에너지 상태에 맞춰 오늘 할 청소 루틴을 고르고 체크하는 플래너입니다. 개발자(솔라메멘토)는 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리방침을 안내합니다.

1. 기본 원칙 — 기록은 기기에, 계정은 선택

  • 본 앱은 계정 없이 사용할 수 있으며, 이 경우 모든 기록은 이용자 기기 안에만 저장되고 외부로 전송되지 않습니다.
  • 본 앱에는 광고, 분석(애널리틱스) 도구, 서버 푸시 알림이 없습니다.
  • 아래 2·4항의 정보는 이용자가 해당 기능을 직접 선택했을 때만 처리됩니다.
  • 본 앱은 ADHD 진단·치료를 대신하지 않으며, 의료 정보를 수집하지 않습니다.

2. 선택 기능: 계정 만들기와 클라우드 동기화

폰과 웹(chagunchagun.expo.app)에서 같은 기록을 보기 위해 계정을 만들 수 있습니다. 이때 처리되는 정보는 다음과 같습니다.

항목내용목적
이메일 주소, 비밀번호비밀번호는 해시 처리되어 원문이 저장되지 않습니다. 비밀번호 재설정 메일 발송에 이메일을 사용합니다.로그인, 본인 계정 식별
동기화 기록루틴과 체크 기록·내 루틴·챌린지·테마 등 설정·알림 시각기기 간 동기화와 복원
  • 동기화 기록은 이용자 본인만 읽고 쓸 수 있도록 데이터베이스 수준에서 제한됩니다(행 수준 보안).
  • 전송과 저장은 모두 HTTPS로 보호됩니다. 다만 종단간 암호화는 아니며, 기록은 서버에 평문으로 저장됩니다.
  • AI 기능에 쓰는 API 키(4항)는 동기화 기록에서 제외되며 클라우드에 올리지 않습니다.
  • 보관 위치: Supabase(클라우드 데이터베이스 서비스). 보관 기간: 이용자가 계정을 삭제할 때까지.

3. 계정과 데이터 삭제

  • 앱 안에서 더보기 → 설정 → 계정 → 계정 삭제를 누르면 계정과 클라우드 기록이 즉시 삭제되며 되돌릴 수 없습니다. 이 기기에 있는 기록은 남습니다.
  • 계정은 두고 기록만 지우려면 같은 설정 화면의 모든 데이터 초기화를 사용합니다(이 기기와 클라우드 기록을 함께 지웁니다).
  • 앱을 삭제하면 기기에 저장된 기록이 함께 삭제됩니다(계정을 만든 경우 클라우드 기록은 위 방법으로 별도 삭제).
  • 앱을 열 수 없는 경우 계정 삭제 안내 페이지의 방법으로 이메일로 요청할 수 있습니다.

4. 선택 기능: AI 도우미

이용자가 본인의 API 키(Anthropic Claude 또는 Google Gemini)를 직접 등록한 경우에만 동작하는 선택 기능입니다.

  • API 키는 이용자 기기에만 저장되며 클라우드 동기화 기록에 포함되지 않습니다.
  • "지금 뭐부터 하지?" 추천이나 루틴 다듬기를 사용할 때, 이용자가 적은 상황 설명과 루틴 목록 같은 텍스트가 이용자의 키로 해당 AI 서비스에 기기에서 직접 전송됩니다. 개발자의 서버를 경유하지 않습니다.
  • 전송된 데이터의 처리에는 각 제공사의 개인정보처리방침이 적용됩니다: Anthropic · Google
  • 이 기능을 사용하지 않으면 AI 관련 데이터 전송은 일어나지 않습니다.

5. 알림

루틴·구역 알림은 기기 안에서 예약되는 로컬 알림입니다. 알림 서버나 푸시 토큰을 사용하지 않으며, 이용자가 알림 권한을 허용한 경우에만 표시됩니다. 정확한 시각에 울리려면 기기의 "알람 및 리마인더" 권한이 필요할 수 있으며, 허용하지 않으면 몇 분의 오차를 두고 표시됩니다.

6. 내보내기·가져오기

기록을 파일로 내보내거나 붙여넣어 가져오는 기능은 이용자가 직접 실행하며, 파일의 보관과 전달은 이용자가 결정합니다.

7. 제3자 제공 및 위탁

  • 개발자는 이용자 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.
  • 계정 기능을 쓰는 경우 Supabase Inc.가 데이터베이스와 인증 서비스를 제공합니다(위탁).
  • AI 기능을 쓰는 경우 이용자가 직접 해당 AI 제공사에 데이터를 전송합니다(4항).

8. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
